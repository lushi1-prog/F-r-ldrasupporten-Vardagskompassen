Det som bygger trygghet ❤️

En trygg vardag byggs av många små saker. Kärlek, närvaro, bekräftelse, tydlighet, ramar, återhämtning och att få känna att man duger. Allt behöver inte fungera perfekt varje dag. Det viktiga är vad barnet får med sig över tid.

Flera delar som hjälper i vardagen
Den psykologiska tallriksmodellen används här som en enkel bild för att se vilka delar som kan behöva mer plats.
❤️ Kärlek Att känna sig omtyckt, viktig och trygg.
👨‍👩‍👧 Närvaro Att få tid, kontakt och uppmärksamhet.
💬 Bekräftelse Att bli lyssnad på och tagen på allvar.
🌱 Självkänsla Att få känna: jag duger och jag kan lära mig.
😴 Återhämtning Sömn, vila, lugn och tid att landa.
🧭 Ramar Trygga gränser och vuxna som visar vägen.

Vad återkommer?

Ibland blir samma situationer jobbiga om och om igen. Att se när det händer kan göra det lättare att prova något nytt.

🔎 När blir det ofta svårt? Skriv ner tid på dagen, vad som hände precis innan och hur barnet och du reagerade.
🌡️ Hur var läget innan? Var någon trött, hungrig, stressad eller redan ledsen?
🔁 Vad brukar hända efteråt? Se om samma mönster upprepas. Det är inte för att hitta skuld – utan för att hitta en möjlighet att göra annorlunda.
